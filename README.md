# SmartFace - Sistema de Verificación de Identidad

SmartFace es una aplicación web para verificar la identidad de personas mediante la comparación de una imagen de ID con una foto capturada en tiempo real o subida por el usuario.

## Características

- Interfaz de usuario moderna y responsive
- Autenticación de usuarios
- Carga de imágenes de identificación
- Captura de fotos en tiempo real usando la cámara web
- Verificación de identidad utilizando Azure Face API
- Arrastrar y soltar para cargar imágenes
- Animaciones y efectos visuales

## Tecnologías utilizadas

- HTML5, CSS3 y JavaScript
- Bootstrap 5 para el diseño responsive
- Azure Face API para la detección facial
- Font Awesome para iconos

## Desarrollo local

Para ejecutar la aplicación localmente:

1. Clona este repositorio
2. Abre el archivo `index.html` en tu navegador

## Notas

- Esta aplicación es una demostración y utiliza autenticación del lado del cliente
- La verificación de identidad es simulada en la versión desplegada
- En un entorno de producción, se recomienda implementar autenticación del lado del servidor y utilizar HTTPS
